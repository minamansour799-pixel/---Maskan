​Project Overview
​Sakanak is a specialized rental marketplace designed for students, expats, and newlyweds in Egypt. Unlike traditional platforms, Sakanak acts as a continuous mediator between landlords and tenants. It ensures 100% credibility by banning brokers and using an AI-driven verification system that matches property videos with descriptions. The platform manages the essential rental lifecycle, including insurance deposits and monthly payments.

​Project Objectives
​Eliminate Exploitation: Removing brokers and hidden commissions from the rental process.
​Ensure Trust: Using AI and official document verification (National ID & Proof of Ownership) to prevent fraud.
​Streamline Payments: Providing a secure in-app gateway for rent and insurance deposits.
​Property Preservation: Implementing a photo-based check-in/check-out system to protect the rights of both parties.

Final Deliverable: A comprehensive UI/UX Case Study for the Sakanak application, including a high-fidelity interactive prototype, a verified property listing system, and a coded landing page.
